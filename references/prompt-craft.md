## 1. 景别

| 景别 | 剧情用途 |
|---|---|
| 大全景/远景 | 交代环境和人物的孤立感，常作开场或结尾 |
| 全景 | 人物全身与空间关系，交代动作路线 |
| 中景 | 腰部以上，日常动作和两人互动 |
| 中近景 | 胸部以上，对白的默认景别，口型最稳 |
| 近景 | 肩部以上，情绪反应 |
| 特写 | 面部局部或关键道具，制造停顿和暗示 |

一段内景别要有变化，常用顺序是由远到近建立空间，再在情绪点用特写。

## 2. 运镜

| 运动 | 写法 | 剧情用途 |
|---|---|---|
| 固定 | 固定机位 | 对白、凝视、压抑情绪 |
| 推 | 镜头缓慢推近<主体> | 进入人物内心，强调发现 |
| 拉 | 镜头缓慢后拉 | 揭示环境，人物被留下或远去 |
| 摇 | 镜头从<A>摇向<B> | 顺着视线揭示对象 |
| 跟 | 镜头跟随<主体>向前移动 | 追赶、行走、紧张感 |
| 升降 | 镜头缓慢升高俯瞰 | 结尾抽离，命运感 |
| 手持 | 轻微手持晃动，跟拍<主体> | 纪实感、慌乱 |
| 环绕 | 镜头绕<主体>半圈 | 关键时刻、情绪爆发 |

- 一镜到底、希区柯克变焦、航拍、FPV、子弹时间、回弹变速等热门运镜可以直接写，但要写清作用主体、起点、方向和终点：`运镜方式 + 作用主体 + 起始位置 + 运动方向 + 到达位置`。
- 小众或含义不统一的术语展开成可见效果，例如「移焦，焦点从前景的咖啡杯平滑转到背景的人物，咖啡杯逐渐虚化」。
- 每个镜头只写一种主运动，需要两种就拆成两个镜头；写清速度（缓慢、匀速、急促）。

## 3. 剧情镜头语法

- **正反打**：两人对话时，镜头1拍 A 说话，镜头2拍 B 反应，一人一镜，同一镜头里另一人自然闭口。
- **过肩镜头**：从 A 肩后拍 B，交代两人的距离和关系。
- **插入特写**：在动作中插入道具特写（戒指、钥匙、未接来电），交代信息。
- **视线匹配**：镜头1人物望向某处，镜头2拍她看到的东西。
- **因果揭示**：先让观众看清触发原因，再给人物反应；不要在原因出现前就推成纯面部特写。
- **站位**：参照门、桌子、柜台、车辆等固定物体写内外、前后、朝向和距离，例如「店员站在收银台内侧，林夏坐在临街窗边，两人之间隔着货架」，不要只写画面左右。
- **轴线**：对话和行走保持同一屏幕方向；向左走的人在下一个镜头也向左走。
- **动作接动作**：镜头1开始一个动作（推门），镜头2从另一角度完成它。

## 4. 表演

需要控制演技时按这个顺序写：

`情绪方向 + 触发事件 + 即时可观察反应 + 逐渐变化 + 最终外在表现`

例：「看到店员走来，林夏敲杯沿的手指停住，视线从窗外收回；她抬头勉强笑了一下，肩膀仍然紧绷。」

| 情绪 | 可见动作 |
|---|---|
| 紧张 | 手指反复摩挲衣角，吞咽，目光快速扫向门口 |
| 失落 | 肩膀慢慢塌下，视线落在地面，手里的东西松开 |
| 愤怒 | 下颌收紧，呼吸加重，手掌压在桌面上 |
| 心动 | 先移开视线又偷偷看回去，嘴角压不住地上扬 |
| 犹豫 | 手伸到门把上停住，又缩回来 |
| 释然 | 长出一口气，肩膀放松，抬头看天 |

- 只挑一两个最清楚的眼神、眉头、嘴角、呼吸或手部动作，堆满微表情会让表演夸张。
- 动作优先概括描述（「两人展开近身搏斗」），只在有记忆点的动作上写细节，不重复写同一个动作。
- 表情写描述句而不是成语：「津津有味地吃饭」写成「脸上带着满足的笑容，大口吃饭」。
- 避开「狂热」「极度震惊」等强烈情绪词，它们容易让瞳孔发光；必须表现强烈情绪时，补一句「人物为正常人眼，不发光」。

## 5. 光影与色调

- **时段**：清晨冷白、正午硬光、黄金时刻暖金、蓝调时刻、深夜霓虹。
- **主光方向**：侧光制造情绪，逆光勾勒轮廓，顶光显得压抑，窗光显得生活化。
- **色温对比**：冷暖对比（窗外冷蓝、室内暖黄）最适合表现孤独和对照。
- **类型片基调**：悬疑用低调光和大面积暗部；温情用柔和暖光；古装用柔光和低饱和；都市职场用干净冷白。

风格句一旦定下，各段逐字复用，不在单段里改基调。

## 6. 声音与台词

| 内容 | 符号 | 示例 |
|---|---|---|
| 台词 | `{}` | `林夏台词（轻声）：{好，我再等五分钟。}` |
| 音效 | `<>` | `<门铃叮咚一声>` |
| 音乐 | `()` | `(低沉缓慢的钢琴单音，音量低于风声)` |
| 屏幕字幕 | `【】` | 只在用户要求字幕时使用 |

- **对白**：`说话人台词（语气）：{台词}`。同一人多句、语气不同时拆成多行，每行一个语气。台词用口语短句，说完就结束，不在后面复述词语或追加神态描述（容易诱发字幕）。
- **语气词**：轻声、压低声音、带笑、哽咽、急促、平静地、声音发颤、半开玩笑地。
- **语言**：用户指定语言、方言或口音时写明，如「使用英语」「带东北口音」；用户没指定时不擅自添加。
- **多人对白**：逐镜头写明谁说话，其他人物「自然闭口聆听」。
- **无对白片段**：写「人物自然闭口，没有旁白」，只保留指定的环境声和音效。
- **音效**：写具体来源，如「高跟鞋踩在瓷砖上」「纸张翻动」。音效用 `<>` 时，角色名不要再用尖括号。
- **配乐**：像给作曲写需求：乐器 + 速度 + 情绪 + 音量位置。不要配乐时写「音频不包含任何音乐、背景音乐、BGM、配乐或旋律」；仍有配乐漏出时，把这句同时写在提示词开头和结尾。
- **主次**：用一句话排出谁在上，如「对白清晰突出，环境声低垂在下」。

## 7. 失败模式

- **眼睛发光**：强烈情绪词让瞳孔出现蓝光、红光。修复：改用常规情绪词，补「人物为正常人眼，不发光」。
- **角色互换**：多人物时角色和参考图、音色对不上。修复：按首次出场顺序上传，一行一个主体映射。
- **意外字幕**：写了不要字幕仍出现。修复：去掉台词后的复述和追加描述，按「台词（语气）：{}」拆分；确认参考视频不带字幕。
- **配乐漏出**：写了无背景音乐，部分音效仍被做成配乐。修复：列全音乐类同义词，开头结尾各写一次。
- **音频噪声**：出现冒水泡声、回音或啸叫。修复：删去与水、波浪、回音相关的描述。
- **文字错误**：画面中的字出现错别字或拼错。修复：尽量不出现文字；必须出现时把正确文字做成参考图，英文可以要求字母按顺序逐个出现。
- **复杂任务不稳定**：一次生成同时承担多项参考和编辑要求。修复：拆成几个简单任务分别生成，再剪辑合成。
- **角色漂移**：同一个人在不同片段换了称呼或描述。修复：名字和外观句逐字复用；有条件时用参考图。
- **场景堆砌**：一段里跑三个地点。修复：一段一个主场景，换场景就换片段。
- **一镜多运动**：同时推、摇、环绕，画面抖动。修复：一个镜头一种运动。
- **时间段过密**：某个时间段塞进太多情节，被过度剪切或漏掉。修复：减少阶段或合并次要事件；不要用时间戳控制频率（如「一秒摇头三次」）。
- **跨版本拼接**：不同片段用了 2.0 和 2.5，画风不一致。修复：整组用 2.5；必须保留 2.0 片段的风格时，以它为输入做延长，输出选 MOV。

## 8. 片段之间的剪辑衔接

相邻两段之间要有观众看得懂的镜头逻辑：上一段的最后一个镜头抛出一个状态或悬念，下一段的第一个镜头换一个机位或景别回应它。

| 方式 | 上一段结尾 | 下一段开头 |
|---|---|---|
| 因果 | 原因或悬念：活鲨钻进一条近道 | 结果：活鲨从近道出口冲出，追到对手身旁 |
| 动作接动作 | 动作开始：她伸手推门 | 换角度完成动作：店外看她推门而出 |
| 视线匹配 | 人物望向窗外 | 她看到的东西：空荡的街口 |
| 反应 | 事件发生：屏幕上鲨鱼撞壁 | 看到事件的人的反应 |
| 声音衔接 | 下一段的声音提前进入，如远处传来引擎声 | 画面切到声源 |
| 对比 | 喧闹、高速、明亮 | 寂静、静止、黑暗 |
| 时间跳跃 | 明确的时间标记，如钟表、天色 | 新时间里的同一地点或人物 |

- 两段之间换机位或景别，让观众清楚这是一次切换；不用遮挡、匹配等手段把切点藏起来做成一镜到底。
- 人物的运动方向、视线方向和所处状态在两段之间保持一致，除非剧情有意改变。
- `衔接：` 行写明上一段结尾画面、下一段开头画面和用的是哪种方式。
- 用户明确要求一镜到底或画面严格接续时，才使用 assets-and-continuity.md 里的延长、首尾帧或视频无缝转场。
